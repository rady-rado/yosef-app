# Yosef — gestion financière simple pour petits entrepreneurs

Yosef aide à suivre l'argent, le stock, la production et les ventes d'une petite entreprise, sans jargon comptable et sans formation.

**Essayer en ligne :** https://rady-rado.github.io/yosef-app/

## Fonctions
- Capital, achats, stock, production, ventes, règlements clients et fournisseurs, épargne
- Tableau de bord, rapports par jour ou par période (imprimables)
- Plusieurs entreprises dans un même outil

## Utilisation
Ouvrez le lien dans Chrome ou Edge, ou téléchargez `index.html` et ouvrez-le sur votre ordinateur.

## Vos données
Elles restent **sur votre appareil** (dans le navigateur, et dans un fichier `.json` si vous le liez depuis le menu « Mes données »). Rien n'est envoyé à un serveur. **Faites des sauvegardes régulières** avec « Exporter la sauvegarde » : si vous videz le navigateur ou changez d'ordinateur sans sauvegarde, les données sont perdues.

## Limites actuelles
- Prototype : pas de mot de passe ni de chiffrement.
- Les données ne sont pas partagées entre appareils ou utilisateurs.
- Polices et graphique chargés depuis internet (pas encore 100 % hors ligne).
- Ne remplace pas un expert-comptable.
